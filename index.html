Graph RAG · Neo4j · Benchmark

graphrag-neo4j

Natural-language questions over 53,000 field-service records, answered from a Neo4j knowledge graph and benchmarked against plain vector RAG on the same data, database and embeddings. Graph RAG could answer 21 of 25 questions exactly, against 0 for vector RAG, using a fifth of the context tokens. The LLM produces a typed query plan, never Cypher, and every graph answer is checked against an independent Python implementation on 300 random plans.

Shows: when graph RAG beats vector RAG, measured honestly, including where it doesn't.

Django · GenAI · Human in the loop

django-invoice-agent

A Django + DRF service that reads supplier invoices from email with Claude, costs each one to the right job, and escalates anything it can't match safely, with a reason a reviewer can act on. The model only reads; deterministic code decides. It posts each invoice exactly once under webhook retries, task redelivery and concurrent duplicates, and PostgreSQL race tests prove it.

Shows: production Django with an LLM that can't move money on its own.

LLMOps · CI/CD

llm-release-gate

A regression evaluation harness wired into CI as a required check: an LLM change that makes behaviour worse fails the pull request. Tiered scoring, absolute safety floors that a worse baseline can't override, and a self-test that fails if the gate ever stops gating.

Shows: no model change ships without passing regression evals.
