A regression evaluation harness wired into CI as a required check: an LLM change that makes behaviour worse fails the pull request. Tiered scoring, absolute safety floors that a worse baseline can't override, and a self-test job that fails if the gate ever stops gating.

Agent safety · PostgreSQL

agent-guardrail-runtime

Seven composable middleware layers around an agent's model call: kill switch, input/output guardrails, human approval, per-tenant spend cap, audit trail, tracing and retries. Tenant isolation is enforced by PostgreSQL row-level security rather than by remembering to filter queries.

Design decisions recorded as ADRs; isolation proven by adversarial tests.
